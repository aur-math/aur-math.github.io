# KIDmath

一个可离线安装的 iPad 数学小测 PWA。

## 本地测试

```bash
python3 -m http.server 8000
```

然后打开 `http://localhost:8000`。

## iPad 安装测试

1. 让电脑和 iPad 连接同一个 Wi-Fi。
2. 在电脑运行本地服务。
3. 用 `ipconfig getifaddr en0` 查看电脑的 Wi-Fi 局域网地址。
4. 在 iPad Safari 打开电脑的局域网地址，例如 `http://192.168.1.20:8000`。
5. 点击 Safari 分享按钮，选择“添加到主屏幕”。

局域网 HTTP 适合真机预览。若要完整测试离线缓存和正式 PWA 行为，建议部署到 HTTPS 地址后再从 iPad 安装。

## 功能

- 按年级设置题目难度。
- 可选择加、减、乘、除。
- 可设置题目数量和考试时间。
- 考试页倒计时。
- 题目可直接输入答案。
- 固定草稿区支持手写验算和清空。
- 到时或交卷后自动判分。
- 错题会用红色突出显示。
- 成绩页显示已用时间和剩余时间。
- 每次交卷会自动生成成绩快照，并保存在主页历史记录里。
